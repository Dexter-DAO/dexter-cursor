Which result style?
A — ranked cards: top result accented with a bright orange bar, dot-rating quality score, room for a description line. Scannable, more "designed."
B — dense table: more results per screen, columnar, institutional. Less warm, very fast to scan. Closer to Bloomberg.
My lean: A — the description line genuinely helps a user pick, and the accented top result guides the eye. B if you expect users to compare many results at once.
